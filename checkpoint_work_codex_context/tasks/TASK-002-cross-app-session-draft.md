# TASK-002：アプリをまたいで調べものを続ける
状態：草案（TASK-001と時間計測等の決定後に実行可能へ変更）
基準ブランチ・コミット：未取得

## 目的
YouTubeからChromeへ移動するたびに目的や帰還点を再入力する負担を減らし、同じ調べものとして管理する。
## 期待動作
CP-04〜10。続き／別目的／開かないを確認し、続きならセッションID・目的・帰還点・残り時間を継承する。
別目的は旧セッション終了後に新規目的を設定。延長は同じ目的セッション。終了時は目的と帰還点を再提示。
## 実行前の決定
時間計測方式、確認画面中の計測、HOME・ロック・再生成時の扱い、対象アプリの範囲、切替確認を出す条件、旧履歴との互換性。
セッション中に同じアプリへ復帰する時や、別目的の入力をキャンセルする時の扱いも決める。
## 変更対象
TASK-001で特定する。SessionManager／タイマー／オーバーレイ／連携／履歴は候補名で、存在を確認する。
## 完成条件
主シナリオと境界ケースで目的・時間・帰還点が正しく維持される。二重表示・二重記録・意図しない時間リセットがない。
必要な自動検証が通り、Pixel 7aで主シナリオが通る。SPEC・STATUS・DECISIONS・VALIDATIONが一致する。
## 検証
状態遷移・時間計測の自動テストと、VALIDATIONの実機シナリオを行う。
