## アプリ横断の主シナリオ
1. 帰還点を「数学の宿題」に設定。
2. YouTubeで「二次関数の解説を見る」、予定時間を設定。
3. Chromeへ移動し「続き」を選択。
4. 同じセッションID、目的、帰還点、計測方式に沿った残り時間が維持される。
5. HOME→ロック→再開時に、決定した時間計測・表示仕様どおりに動く。
6. 時間終了後に目的を再提示。達成を選び、帰還点の提示からHOMEへ移動。
実際に勉強へ戻ったかは、本人の別報告として記録する。
