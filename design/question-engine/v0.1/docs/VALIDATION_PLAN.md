# 6形式問題エンジン＋外部作問：検証計画 v0.1

## データ／採点（自動テストの最低条件）
- 単一選択：並び替えても同じIDで正解、未選択の提出禁止。
- 複数選択：集合比較、順不同、選択数上限、正解の一部のみ選んだ場合の結果内訳。
- テキスト：全半角(NFKC)・前後空白・別解・表記揺れ可否を個々の設定に従って判定。
- 数値：`56`、`056`、`56.0` の扱いを規則に従って判定。負数、小数、許容誤差、単位誤り。
- 表：3×3で入力セル数可変、部分正解・誤った列・存在しないセルIDの拒否。
- 操作：順序入替、複数グループ、どの項目も1グループに配置、キーボード/移動ボタン代替。
- 語群：複数空欄、同じ文字列の別トークン、再利用禁止／許可、空欄未入力。
- 自己採点：模範解答閲覧後に自分で評価でき、正解・不正解の自動断定なし。
- 共通：答え合わせ確認前はゲート未完了、正解でも不正解でも確認後に `UNLOCKED`、二重イベントで重複せず、状態復元。

## 外部の問題集
- サンプル`cpq.json`10問を形式検証＋論理検証→プレビュー→取り込み→出題→エクスポートしてID・採点キー維持。
- CSVの単一・複数・テキスト問題を読み込んでプレビュー。複数選択は区切り文字の誤入力を検出。
- AI生成JSONで欠落必須フィールド、正答キーの未存在、重複ID、未知の形式、空欄不整合を拒否。エラー位置を表示。
- ZIP取り込み後、パス走査・大量展開・壊れた画像・外部URL・悪意ある本文がコード実行されないこと。
- 他人の作成問題を読み込んでも作者・出典・利用許諾表示が残り、勝手な公開／クラウド送信なし。

## 実機（Pixel 7a必須）
- 起動→出題→回答→答え合わせ→対象アプリ復帰を6形式各3回。回答画面の戻る・端末ロック・画面回転・キーボード・スクリーンリーダー・文字拡大も確認。
- HOME、YouTube→Chrome、電話着信、アクセシビリティOFF、オーバーレイ拒否、再生成時の安全動作を検証。
- 問題が0問、問題集破損、採点例外、画面表示失敗でも無限に使用不能にならない。
- オフラインでもインポート済問題の出題と採点ができる。
- 先行するセッション改修 TASK-002 と整合。学習ゲート表示中に元の利用タイマーを進めないかは既存D-007の決定を踏まえて統一。
