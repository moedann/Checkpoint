# TASK-006：学習問題→答え合わせ→対象アプリ利用再開
状態：設計草案／依存：TASK-002の現行目的セッション仕様確認、TASK-003/004

## 目的
ユーザーが指定した対象アプリで学習支援モードが有効なときだけ復習を挟む。回答後の正解・不正解に関係なく、答え合わせ確認によって再開可能とする。

## 実装
- 通常目的確認と学習チェックポイントを矛盾なく統合。繰返し同じ情報を聞かない。
- Gate状態機械、重複イベント対策、画面中断・復帰、空問題集、権限停止、安全スキップ、既存の目的セッション引継ぎ。
- Androidの背景Activity起動制約やHIDE_OVERLAY_WINDOWS等、提供できない導線を検証して安全な代替UIを導入。
- ロック中・通話・緊急・アラーム・設定画面は介入しない。タイマーの停止・再開はD-005/007と整合する。

## 完成条件
Pixel 7aで6方式をそれぞれ起動→回答→答え合わせ→元の対象アプリを利用できる。誤答でも同様。試験がない/故障/中断で解除不可ループを作らない。YouTube→Chrome、HOME、再起動、権限解除で二重表示しない。自動テスト・ビルドと実機ログを別に記録。
